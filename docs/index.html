// getting-started

四步上手

setup.sh

01$ git clone https://github.com/liudch036/Buff-translate.git

# 从 GitHub 下载源码（或直接下载 ZIP 解压）

02$ open chrome://extensions

# 开启"开发者模式" → "加载已解压的扩展程序" → 选择项目目录

03$ config --api-key sk-*** --base-url https://api.deepseek.com --model deepseek-flash

# 点击工具栏图标填入配置，点"测试连接"确认可用

04$ buff-translate --enjoy

# 任意网页点击"翻译整页"，或选中文字体验划词翻译
